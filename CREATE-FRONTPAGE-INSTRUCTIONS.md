## How to Use:

1. **Install the Theme:**
   - Zip the `zk-futuristic-theme` folder
   - WordPress → Appearance → Themes → Add New → Upload Theme
   - Activate

2. **Create Homepage:**
   - Pages → Add New
   - Title: "Home"
   - Content: Leave empty or add brief text
   - Publish

3. **Set as Front Page:**
   - Settings → Reading
   - Select: "A static page"
   - Homepage: "Home"
   - Posts page: "Blog" (create this page first)
   - Save

4. **Create Navigation:**
   - Appearance → Menus
   - Add Custom Links:
     - Home: `#home`
     - About: `#about`
     - Skills: `#skills`
     - Projects: `#projects`
     - Experience: `#experience`
     - Contact: `#contact`
     - Blog: `/blog` (full URL)
   - Assign to: "Primary Menu"
   - Save

## The template will automatically show ALL sections in one scrolling page!

All animations, gradients, and effects from the original index.html are preserved.
