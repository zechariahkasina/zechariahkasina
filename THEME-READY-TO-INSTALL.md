## 🚀 How to Install (3 Easy Steps)

### Step 1: Prepare the Theme

```bash
# Option A: Download from GitHub
Download the zk-futuristic-theme folder from your repository

# Option B: Create ZIP
cd zechariahkasina
zip -r zk-futuristic-theme.zip zk-futuristic-theme/
```

### Step 2: Upload to WordPress

```
1. Log into zechariahk.com/wp-admin
2. Go to Appearance → Themes → Add New
3. Click "Upload Theme"
4. Choose zk-futuristic-theme.zip
5. Click "Install Now"
6. Click "Activate"
```

### Step 3: Configure Settings (5 minutes)

#### A. Create Pages
```
Pages → Add New
- Title: "Home" → Publish
- Title: "Blog" → Publish
```

#### B. Set Homepage
```
Settings → Reading
- Select: "A static page"
- Homepage: "Home"
- Posts page: "Blog"
- Save Changes
```

#### C. Create Navigation Menu
```
Appearance → Menus
- Create new menu: "Primary Menu"
- Add Custom Links:
  * Home: #home
  * About: #about
  * Skills: #skills
  * Projects: #projects
  * Experience: #experience
  * Contact: #contact
  * Blog: /blog
- Assign to: "Primary Menu"
- Save Menu
```

#### D. Site Identity
```
Appearance → Customize → Site Identity
- Site Title: Zechariah Kasina
- Tagline: Senior DevOps Engineer at AWS | Cloud Infrastructure Specialist
- Save & Publish
```

#### E. Permalinks
```
Settings → Permalinks
- Select: "Post name"
- Save Changes
```

## 🐛 Troubleshooting

### Theme not activating?
- Check PHP version (7.4+)
- Verify all files uploaded
- Check error log in WordPress

### Sections not showing?
- Confirm "Home" page is set as homepage
- Check Settings → Reading
- Clear browser cache

### Animations not working?
- Check JavaScript errors in browser console
- Verify animations.js loaded
- Clear browser cache

### SEO tags not appearing?
- View page source (Right-click → View Page Source)
- Look for `<meta property="og:` tags
- Check functions.php loaded correctly
