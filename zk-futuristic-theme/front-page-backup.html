About Me

Building Bridges Between Cloud & Innovation

Hello! I'm Zechariah Kasina, a Senior DevOps Engineer at Amazon Web Services based in Lake Oswego, Oregon. I specialize in creating scalable cloud infrastructure, serverless applications, and AI-powered solutions that solve real-world challenges.

My mission is to bridge the gap between cutting-edge AWS services and practical implementations that developers can learn from. Whether it's Infrastructure as Code templates, AI document processors, or automation scripts, I'm passionate about making complex cloud technologies accessible.

I spend my days working with ECS Fargate, Lambda, and Amazon Bedrock, while contributing educational content to the AWS Community. I'm particularly excited about emerging technologies like Model Context Protocol servers and building practical tools for document processing and content management.
